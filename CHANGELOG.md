# Changelog

## [0.1.0] - 2026-05-20

### Added
- `convert` module: COCO, YOLO, VOC, LabelMe, CSV format conversion
- `augment` module: synthetic defect generation (cracks, rust, scratches) + industrial augmentation pipeline
- `analyze` module: dataset profiler, health score, visualizer, severity scorer
- `validate` module: annotation validator and auto-fixer
- `benchmark` module: defect model benchmarking and comparison
- `deploy` module: ONNX export and edge device optimization
- `taxonomy` module: standardized industrial defect naming (30+ types)
- `DefectPipeline`: one-command end-to-end pipeline
- CLI: `opendefectkit` command with all subcommands
